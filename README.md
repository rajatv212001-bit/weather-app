# 🌦️ Weather App

A simple and responsive weather application built with HTML, CSS, and JavaScript.

Search for any city and get current weather information using a weather API.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Display current temperature
- 💧 Show humidity
- 💨 Show wind speed
- ☁️ Display weather conditions
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API

## 🚀 How to Use

1. Open the Weather App.
2. Enter the name of a city.
3. Search for the city.
4. View the current weather information.
